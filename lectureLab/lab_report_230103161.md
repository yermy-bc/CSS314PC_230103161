### 1.4 Measurement methodology

### 2.1 Cache-line boundary identification

The medians at p = 4 are noisy. IQRs reach 260–770 ms because Windows sometimes places two of the four workers on the two hyper-threads of one core. Those siblings share an L1d, so no coherence traffic flows between them, and the run-time distribution splits into fast and slow runs. The script's "sharpest median drop" (32 B) comes from a single unusually tight sample set (IQR 33 ms) and does not reflect the coherence boundary.

The **minimum** time (the run least disturbed by the OS) and the group averages make the step clear:

| slot separation | mean of medians | mean of minima | regime |
|---|---:|---:|---|
| 8–64 B (strides 1, 2, 4, 8) | 2094.9 ms | 1855.9 ms | slots share a 64-B line, or an adjacent line of the same 128-B pair |
| 128–256 B (strides 16, 32) | 1894.9 ms | 1600.0 ms | every slot in its own 128-B aligned line pair |
| **improvement** | **−9.5 %** | **−13.8 %** | |

The fastest single runs drop from 1805–1905 ms down to **1539 ms exactly at 128 B (stride 16)**. On this CPU the coherence line is 64 B (as `GetLogicalProcessorInformation` reports), but the Intel L2 **spatial (adjacent-line) prefetcher** fetches lines in 128-B aligned pairs. At a 64-B separation, slots 2k and 2k+1 still sit in the same line pair, and a store by one core pulls in, or invalidates, its neighbour's line. Interference disappears completely only at **128 B**, which is why stride 16 serves as the "isolated" case. An earlier calibration run of this same kernel on this laptop (M = 1.6·10⁷) showed the same two-step pattern, with a −13.4 % drop at 64 B followed by a further −12 % at 128 B.

Overall, the false-sharing penalty at p = 4 is only T(s=1)/T(s=16) = 1.09× (median) to 1.20× (min). Each RMW step costs about 80 ns of CPython bytecode work, while an RFO/invalidate round-trip between cores costs about 20–40 ns, so coherence is only part of each step. A C version would show a 5–10× penalty.

### 2.2 Karp–Flatt forensic explanation

The kernel has **no serial code at all**, since every worker runs independently, so any e(p) > 0 measures *parallel overhead*:

* **stride = 1** already has e(2) = 0.151, which is **4.25× higher** than padded (0.036). With two cores writing into one 64-B line, every store needs exclusive (M-state) ownership. The line moves between the cores' L1s on almost every iteration (MESI invalidate + read-for-ownership), and the stores partly serialize through the coherence fabric, behaving like a serial fraction of about 15 %. e(p) then **rises sharply to 0.296 at p = 4**, because four cores now fight over the same line: each store waits behind up to three other owners, so the hidden serialized fraction grows with p. The rise in e(p) is the signature of contention overhead. A true Amdahl serial fraction would keep e(p) flat.
* **stride = 16** stays almost perfectly parallel at p = 2 (E = 0.97, e = 0.036), with no shared lines. At p = 4, e rises to 0.203, but this overhead has nothing to do with coherence. It is frequency: the i5-11300H runs at a lower turbo clock with four active cores than with one or two, so per-core speed drops as p grows. Windows background threads also land on otherwise idle cores. At p = 4 the gap between the two strides (0.296 vs 0.203) is the pure false-sharing component, about **+0.09 of serial fraction**.
* **p = 8 (SMT)**: both curves flatten (0.306 / 0.230), because the 4 extra workers run as hyper-threads that share execution resources. Total throughput rises only 1.2–1.23× compared with p = 4, so efficiency halves and e(p) reflects the limit of 4 physical cores. For stride 1, SMT siblings share the line inside one L1d, so the e(p) curve stops climbing: contention moves from between cores to inside a core.

* The slice copy is a native `memcpy` and does reach DRAM speed. Write-allocate adds a read-for-ownership of the destination, so true bus traffic is about 3 × 96 MB, roughly 18.5 GB/s. That is a typical sustained figure for laptop DDR4-3200, against a theoretical dual-channel peak of 51.2 GB/s.
* The compute ceiling is set by the CPython interpreter. Each `x = x*a + b` runs about 6 bytecodes and allocates a new float object. A Willow Cove core can do 16 DP FLOP/cycle (one 512-bit FMA unit: 8 doubles × 2 FLOP), about 64 GFLOP/s at 4 GHz, so the interpreter runs roughly **1000× below** the silicon.
* Because P is so low, I\* is only **0.02 FLOP/B**. Every kernel with I > 0.02 sits under the flat **compute (interpreter) roof**, and that includes even naive GEMM with I = 0.125.

### 4.3 Cache-capacity analysis

* **BS\* = 48 → W_tile = 54 KB.** That is just above the 48 KB L1d and well inside the 1.25 MB per-core L2. BS = 32 (24 KB, which does fit L1d) is statistically tied with it: 0.05061 vs 0.05092 GFLOP/s, a 13.7 ms difference against IQRs of about 95 ms. The optimum is therefore a **plateau at BS = 32–48**, the largest tiles whose working set stays in or right at L1d and comfortably in L2. Beyond BS = 64 (96 KB, two L1d's worth), throughput falls by about 6 % as tiles stream out of L1d into L2. **The optimal footprint fits cleanly in L2 (54 KB ≪ 1.25 MB), and the tied BS = 32 fits L1d**, which satisfies audit check (c).
* **Loop overhead governs the left side of the curve.** BS = 4 is the slowest point (0.037 GFLOP/s). Each 4-element inner `j` loop runs only 4 FMAs but pays for a new `range()` object, a `min()` call and the index set-up, so the interpreter spends more time on loop control than on arithmetic. Throughput rises steadily up to BS ≈ 32–48, until the control overhead is amortized and cache spill begins.
* **Why V1 beats V2/V3 in Python, the reverse of compiled code.** In V1, the running `dot` lives in a local variable, so each FMA costs **2** buffer reads (A, B). V2 and V3 update `C[iN+j] += …` directly in shared memory, which costs a read and a write of C on every FMA: **3** buffer operations plus a float box/unbox, about +16 % time. Unit-stride access does save cache misses. Each worker touches about 1.7 MB (96 rows of A and C plus all of B), which is more than the 1.25 MB L2, so V1's stride-N walk over B does miss. But each miss costs a few nanoseconds, against about 30 ns of interpreter work per element access. Blocking recovers 3.5 % over V2 by keeping the B tile resident, but cannot remove the extra C traffic in the bytecode.

### 5.1 Analysis

* **Block static (λ = 2.298, analytical 2.313).** Work grows as i², so worker 3's quarter (items 9000–11 999) holds 1 − (3/4)³ = 58 % of all work. Worker 0 finishes after 0.41 s and then idles for 15 s at the join. T_wall equals the slowest worker's time, so 4 cores deliver only 26.9 s of work in 4 × 15.4 = 61.7 core-seconds, a 43 % utilization.
* **Cyclic static (λ = 1.040)** interleaves light and heavy items and balances the analytical work to within 0.04 %. The measured 4 % comes from cores running at slightly different clocks and from OS interruptions. A static schedule cannot react to either.
* **C = 1 vs C = 1024 trade-off:**
  * **C = 1** gives the minimum tail skew: the last claim is a single item, so all four workers finish within 6 ms of each other (λ = 1.000). The cost is 12 000 acquisitions of the `mp.Value` lock. On Windows each one is a kernel semaphore call plus a transfer of the counter's cache line between cores, about 5–20 µs, or 60–240 ms in total. An average item takes about 2.5 ms (13 332 iterations × ~190 ns), so the lock adds well under 1 % here. It still costs something: C = 1 is 1.8 % slower than C = 16.
  * **C = 1024** needs only 12 claims, so synchronization is essentially free. But the chunks are enormous: the final one (items 11 264–11 999) contains **17.3 % of all work** and the one before it 20.6 %. Whichever worker claims the last heavy chunk keeps running while the others are idle (t_worker 5.3 s vs 8.9 s), giving **λ = 1.185** and the worst dynamic T_wall (+16.5 % vs C\*). C = 256 shows the same effect in milder form (λ = 1.105).
  * **C = 16 (C\*)** sits at the balance point. It needs 750 lock operations (16× fewer than C = 1). The tail is bounded by one 16-item chunk, at most 16 × ~7.6 ms ≈ 120 ms for the heaviest items, or 1.6 % of T_wall, so λ = 1.003. C = 64 is almost as good (λ = 1.007, smallest IQR). Statistically, C ∈ {1, 16, 64} are within each other's IQR, and C = 16 has the lowest median.
* **C = 4 anomaly.** C = 4 has λ = 1.001, so it was perfectly balanced. Yet *every* worker's active time rose by the same amount (Σ t_worker 37.0 s vs about 30.5 s for the others), and its min time (7575 ms) is in line with the rest. A slowdown spread uniformly across all workers points to the machine running slower during those runs (frequency or background activity), not to scheduling. λ is a ratio, which is why it isolates imbalance from clock effects. Interleaving the strategies limited the damage to IQR (1571 ms) without biasing the ranking of the other configurations.

```python
def _server(target, args, start_b, done_b, stop):
    """Worker loop: wait for a start signal, run target(*args) once, report done."""
    while True:
        start_b.wait(timeout=BARRIER_TIMEOUT)
        if stop.value:
            break
        target(*args)
        done_b.wait(timeout=BARRIER_TIMEOUT)


class ProcGroup:
    """
    p persistent mp.Process workers, each running target(*args_list[t]) once per
    run() call. Processes are spawned once in __init__, so a run_benchmark(group.run)
    measurement contains only kernel time (+ ~tens of us of barrier release),
    never fork/spawn cost.
    """

    def __init__(self, target, args_list):
        n = len(args_list)
        self.start_b = mp.Barrier(n + 1)
        self.done_b = mp.Barrier(n + 1)
        self.stop = mp.Value("b", 0)
        self.procs = [mp.Process(target=_server,
                                 args=(target, tuple(a), self.start_b, self.done_b, self.stop))
                      for a in args_list]
        for pr in self.procs:
            pr.start()

    def run(self):
        self.start_b.wait(timeout=BARRIER_TIMEOUT)
        self.done_b.wait(timeout=BARRIER_TIMEOUT)

    def close(self):
        self.stop.value = 1
        try:
            self.start_b.wait(timeout=60)
        except Exception:
            pass
        for pr in self.procs:
            pr.join(timeout=60)
            if pr.is_alive():
                pr.terminate()

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        self.close()

def _win_slpi():
    """Windows: GetLogicalProcessorInformation -> (physical cores, {(level,type): size}, line)."""
    import ctypes
    from ctypes import wintypes

    class CACHE_DESCRIPTOR(ctypes.Structure):
        _fields_ = [("Level", ctypes.c_ubyte), ("Associativity", ctypes.c_ubyte),
                    ("LineSize", ctypes.c_ushort), ("Size", ctypes.c_uint32), ("Type", ctypes.c_int)]

    class _U(ctypes.Union):
        _fields_ = [("Flags", ctypes.c_ubyte), ("NodeNumber", ctypes.c_uint32),
                    ("Cache", CACHE_DESCRIPTOR), ("Reserved", ctypes.c_ulonglong * 2)]

    class SLPI(ctypes.Structure):
        _fields_ = [("ProcessorMask", ctypes.c_size_t), ("Relationship", ctypes.c_int), ("u", _U)]

    k32 = ctypes.WinDLL("kernel32", use_last_error=True)
    length = wintypes.DWORD(0)
    k32.GetLogicalProcessorInformation(None, ctypes.byref(length))
    n = length.value // ctypes.sizeof(SLPI)
    buf = (SLPI * n)()
    if not k32.GetLogicalProcessorInformation(buf, ctypes.byref(length)):
        raise OSError("GetLogicalProcessorInformation failed")
    cores, caches, line = 0, {}, None
    for e in buf:
        if e.Relationship == 0:                      # RelationProcessorCore
            cores += 1
        elif e.Relationship == 2:                    # RelationCache
            c = e.u.Cache
            caches[(c.Level, c.Type)] = c.Size       # per-instance size
            if c.Level == 1:
                line = c.LineSize
    return cores, caches, line
```

```python
SharedMemory(create=True, size=4096) -> 512 x uint64 slots. Worker t updates slot

SLOTS = 512

STRIDES = [1, 2, 4, 8, 16, 32]  # 8, 16, 32, 64, 128, 256 bytes


def fs_worker(shm_name: str, slot_idx: int, iters: int) -> None:
    shm = attach_shm(shm_name)
    arr = (ctypes.c_uint64 * 512).from_buffer(shm.buf)
    acc = arr[slot_idx]
    mask = 0xFFFFFFFFFFFFFFFF
    mult = 6364136223846793005
    for i in range(iters):
        acc = (acc * mult + (i | 1)) & mask
        arr[slot_idx] = acc  # Direct hardware store to shared L1 cache line
    del arr  # Release buffer export before closing SharedMemory
    shm.close()


def measure(shm, p, stride, warmup, runs):
    iters = M_TOTAL // p

            "median_ms": st.median_ms, "iqr_ms": st.iqr_ms, "max_ms": st.max_ms, "mops": mops}
```

```python
def stage_a(n_a: int) -> float:
    """Serial reduction/prefix filter: 12 transcendental ops per element."""
    sin, sqrt = math.sin, math.sqrt
    acc = 0.0
    for i in range(n_a):
        x = i * 1e-6 + 1.0
        x = sin(x); x = sqrt(x * x + 1.0)
        x = sin(x); x = sqrt(x * x + 1.0)
        x = sin(x); x = sqrt(x * x + 1.0)
        x = sin(x); x = sqrt(x * x + 1.0)
        x = sin(x); x = sqrt(x * x + 1.0)
        x = sin(x); x = sqrt(x * x + 1.0)
        if x > 0.0:                      # prefix filter
            acc += x
    return acc


def stage_b_chunk(bounds) -> float:
    """35 ops/element: 7 x (FMA, sin, FMA, FMA, cos). Returns a private partial sum."""
    start, end = bounds
    sin, cos = math.sin, math.cos
    a, b, c = 0.999999, 1.000001, 1e-7
    acc = 0.0
    for i in range(start, end):
        x = i * 1e-6
        y = x
        z = 0.5
        for _ in range(7):
            y = y * a + c        # FMA
            y = sin(y)           # trig
            z = z * b + y        # FMA
            y = y * a + x        # FMA
            z = cos(z)           # trig
        acc += y + z
    return acc
```

```python
"""
task3a_roofline.py -- Phase 3A: Characterizing the Laptop's Hardware Roofline
Student: Ainat Yermurat (230103161)

Across p = P_phys persistent worker processes:
 1. BW_sustained: two 96 MB SharedMemory byte buffers (192 MB > L3); each worker

 2. P_sustained: 16 unrolled scalar FMAs (x_k = x_k*a + b), 8.0e7 FLOP per worker.

def bw_worker(name_a, name_b, start, end):

    sa.close()
    sb.close()


def fma_worker(iters):

    b = 1e-9

    for _ in range(iters):
        x0 = x0 * a + b; x1 = x1 * a + b; x2 = x2 * a + b; x3 = x3 * a + b
        x4 = x4 * a + b; x5 = x5 * a + b; x6 = x6 * a + b; x7 = x7 * a + b
        x8 = x8 * a + b; x9 = x9 * a + b; x10 = x10 * a + b; x11 = x11 * a + b
        x12 = x12 * a + b; x13 = x13 * a + b; x14 = x14 * a + b; x15 = x15 * a + b
    return x0 + x1 + x2 + x3 + x4 + x5 + x6 + x7 + x8 + x9 + x10 + x11 + x12 + x13 + x14 + x15
```

```python
"""
task3b_gemm.py -- Phase 3B: Progressive GEMM Optimization & 10-Point Tile-Size Sweep
Student: Ainat Yermurat (230103161)

C = A x B, double precision, N = 384, flat 1-D SharedMemory buffers
(3 x 384^2 x 8 B = 3.54 MB), rows partitioned across p = P_phys workers.
  V1 naive i-j-k      : dot += A[i*N+k] * B[k*N+j]  (B traversed with stride N)
  V2 reordered i-k-j  : a_ik hoisted, unit-stride j over rows of B and C
  V3 6-loop blocked   : (ii,kk,jj) tiles of BS, micro-kernel (i,k,j), a_ik hoisted
                        BS in {4,8,12,16,24,32,48,64,96,128}; verified vs V2 (< 1e-9)
Roofline ceilings are read from results/phase3a.json (run task3a_roofline.py first).
Emits VERIFY_HASH[PHASE3] using GFLOP/s(V1) and GFLOP/s(V3, BS*).
"""
import argparse
import random
import struct
from multiprocessing import shared_memory

from harness import (STUDENT_ID, emit_verify_tag, header, run_benchmark, ProcGroup, attach_shm,
                     save_json, load_json, common_args, resolve_pphys, get_cache_info, fmt_bytes)

N = 384
BS_LIST = [4, 8, 12, 16, 24, 32, 48, 64, 96, 128]
I_NAIVE = 0.125


def _open(na, nb, nc):
    sa, sb, sc = attach_shm(na), attach_shm(nb), attach_shm(nc)
    return (sa, sb, sc), sa.buf.cast("d"), sb.buf.cast("d"), sc.buf.cast("d")


def _close(shms, *views):
    for v in views:
        v.release()
    for s in shms:
        s.close()


def gemm_v1(na, nb, nc, n, r0, r1, bs):
    shms, A, B, C = _open(na, nb, nc)
    for i in range(r0, r1):                       # rows partitioned across workers
        iN = i * n
        for j in range(n):                        # middle loop j
            dot = 0.0
            for k in range(n):                    # inner k, B with stride N
                dot += A[iN + k] * B[k * n + j]
            C[iN + j] = dot
    _close(shms, A, B, C)


def gemm_v2(na, nb, nc, n, r0, r1, bs):
    shms, A, B, C = _open(na, nb, nc)
    for i in range(r0, r1):
        iN = i * n
        for j in range(n):
            C[iN + j] = 0.0
        for k in range(n):                        # middle loop k
            a_ik = A[iN + k]                      # hoisted
            kN = k * n
            for j in range(n):                    # unit-stride rows of B and C
                C[iN + j] += a_ik * B[kN + j]
    _close(shms, A, B, C)


def gemm_v3(na, nb, nc, n, r0, r1, bs):
    shms, A, B, C = _open(na, nb, nc)
    for idx in range(r0 * n, r1 * n):
        C[idx] = 0.0
    for ii in range(r0, r1, bs):                          # loop 1: i tiles
        i_end = min(ii + bs, r1)
        for kk in range(0, n, bs):                        # loop 2: k tiles
            k_end = min(kk + bs, n)
            for jj in range(0, n, bs):                    # loop 3: j tiles
                j_end = min(jj + bs, n)
                for i in range(ii, i_end):                # loop 4: i  (micro-kernel i,k,j)
                    iN = i * n
                    for k in range(kk, k_end):            # loop 5: k
                        a_ik = A[iN + k]                  # hoisted outside j
                        kN = k * n
                        for j in range(jj, j_end):        # loop 6: j, unit stride
                            C[iN + j] += a_ik * B[kN + j]
    _close(shms, A, B, C)


def row_parts(n, p):

    out, s = [], 0
    for w in range(p):
        e = s + q + (1 if w < r else 0)
        out.append((s, e))
        s = e
    return out

    p = resolve_pphys(args)
    cache = get_cache_info()
    roof = load_json("phase3a.json")
    if roof is None:
        raise SystemExit("results/phase3a.json not found -- run task3a_roofline.py first.")
    BW, P, ridge = roof["BW_GBps"], roof["P_GFLOPs"], roof["ridge"]
    print(f"p = P_phys = {p}  N = {N}  footprint = {3 * N * N * 8 / 1e6:.2f} MB  "
          f"warmup_runs={args.warmup} timed_runs={args.runs}")
    print(f"Roofline (Phase 3A): BW = {BW:.2f} GB/s, P = {P:.4f} GFLOP/s, I* = {ridge:.6f} FLOP/B")
    print(f"L1d = {fmt_bytes(cache['l1d'])} per core, L2 = {fmt_bytes(cache['l2'])}, "
          f"L3 = {fmt_bytes(cache['l3'])}")

    nbytes = N * N * 8
    rnd = random.Random(STUDENT_ID)
    A_vals = [rnd.uniform(-1.0, 1.0) for _ in range(N * N)]
    B_vals = [rnd.uniform(-1.0, 1.0) for _ in range(N * N)]
    shA = shared_memory.SharedMemory(create=True, size=nbytes)
    shB = shared_memory.SharedMemory(create=True, size=nbytes)
    shC = shared_memory.SharedMemory(create=True, size=nbytes)
    flops = 2 * N ** 3
    rows = row_parts(N, p)

    def gflops(ms):
        return flops / (ms * 1e-3 * 1e9)

    try:
        shA.buf[:nbytes] = struct.pack(f"{N * N}d", *A_vals)
        shB.buf[:nbytes] = struct.pack(f"{N * N}d", *B_vals)

        def read_C():
            return struct.unpack(f"{N * N}d", bytes(shC.buf[:nbytes]))

        def bench(fn, bs=0):
            shC.buf[:nbytes] = bytes(nbytes)
            with ProcGroup(fn, [(shA.name, shB.name, shC.name, N, r0, r1, bs) for r0, r1 in rows]) as g:

            return sum(A_vals[i * N + k] * B_vals[k * N + j] for k in range(N))

        print(f"\n{'variant':<20} {'median_ms':>10} {'IQR':>8} {'GFLOP/s':>9} {'W_tile':>10} "
              f"{'I FLOP/B':>9} {'%attain':>8} {'max|dC|':>10}")
        st1, C1 = bench(gemm_v1)
        g1 = gflops(st1.median_ms)
        st2, C2 = bench(gemm_v2)
        g2 = gflops(st2.median_ms)
        d12 = max(abs(x - y) for x, y in zip(C1, C2))
        dref = max(abs(C2[i * N + j] - ref(i, j)) for i, j in [(0, 0), (N // 5, (3 * N) // 4), (N - 1, N - 1), (N // 2, 5)])
        att_naive = min(P, I_NAIVE * BW)
        print(f"{'V1 naive i-j-k':<20} {st1.median_ms:>10.1f} {st1.iqr_ms:>8.1f} {g1:>9.5f} {'-':>10} "
              f"{I_NAIVE:>9.3f} {g1 / att_naive * 100:>7.1f}% {'(ref)':>10}")
        print(f"{'V2 reordered i-k-j':<20} {st2.median_ms:>10.1f} {st2.iqr_ms:>8.1f} {g2:>9.5f} {'-':>10} "
              f"{I_NAIVE:>9.3f} {g2 / att_naive * 100:>7.1f}% {d12:>10.2e}", flush=True)
        v3 = []
        for bs in BS_LIST:
            st3, C3 = bench(gemm_v3, bs)
            g3 = gflops(st3.median_ms)
            d32 = max(abs(x - y) for x, y in zip(C3, C2))
            wt = 3 * bs * bs * 8
            I = bs / 12
            att = min(P, I * BW)
            ok = d32 < 1e-9
            v3.append({"BS": bs, "median_ms": st3.median_ms, "iqr_ms": st3.iqr_ms, "gflops": g3,
                       "W_tile_B": wt, "I": I, "attainable": att, "pct_attain": g3 / att * 100,
                       "max_diff_vs_V2": d32, "ok": ok,
                       "fits_L1d": bool(cache["l1d"] and wt <= cache["l1d"]),
                       "fits_L2": bool(cache["l2"] and wt <= cache["l2"])})
            print(f"{'V3 BS=' + str(bs):<20} {st3.median_ms:>10.1f} {st3.iqr_ms:>8.1f} {g3:>9.5f} "
                  f"{fmt_bytes(wt):>10} {I:>9.3f} {g3 / att * 100:>7.1f}% {d32:>10.2e}"
                  f"{'' if ok else '  FAIL'}", flush=True)
            if not ok:
                raise SystemExit(f"Verification failed: BS={bs} max|C3-C2|={d32}")
    finally:
        for s in (shA, shB, shC):
            s.close(); s.unlink()

    best = max(v3, key=lambda r: r["gflops"])
    bs_star, g3s = best["BS"], best["gflops"]
    print(f"\nVerification: max|C2-C1| = {d12:.2e}; V2 vs independent dot products = {dref:.2e}; "
          f"all 10 tiles max|C3-C2| < 1e-9: {all(r['ok'] for r in v3)}")
    print(f"BS* = {bs_star}: {g3s:.5f} GFLOP/s, W_tile = {fmt_bytes(best['W_tile_B'])}, "
          f"I_tiled = BS*/12 = {bs_star / 12:.2f} FLOP/B")
    if cache["l1d"]:
        print(f"Tiles fitting L1d ({fmt_bytes(cache['l1d'])}): {[r['BS'] for r in v3 if r['fits_L1d']]}"
              f"   -> BS* fits L1d: {best['fits_L1d']}")
    if cache["l2"]:
        print(f"Tiles fitting L2  ({fmt_bytes(cache['l2'])}): {[r['BS'] for r in v3 if r['fits_L2']]}"
              f"   -> BS* fits L2: {best['fits_L2']}")
    print(f"Speedups: V2/V1 = {g2 / g1:.3f}x  V3*/V1 = {g3s / g1:.3f}x  V3*/V2 = {g3s / g2:.3f}x")

    print("\nRoofline mapping: attainable = min(P_sustained, I x BW_sustained)")
    for name, I, g in [("Variant 1", I_NAIVE, g1), ("Variant 2", I_NAIVE, g2),
                       (f"Variant 3 (BS*={bs_star})", bs_star / 12, g3s)]:
        att = min(P, I * BW)
        region = "compute(interpreter)-bound" if I >= ridge else "memory-bound"
        print(f"  {name:<22} I={I:7.3f}  attainable={att:.4f}  measured={g:.5f} GFLOP/s  "
              f"-> {g / att * 100:5.1f}% of attainable, {region}")
```

### `task4_scheduling.py`

```python
"""
task4_scheduling.py -- Phase 4: Skewed Workloads, Load Imbalance & Dynamic Work Stealing
Student: Ainat Yermurat (230103161)

Triangular skew: N = 12,000 items, item i runs K(i) = 1 + floor((i/60)^2)
iterations of (math.sin, math.cos, math.sqrt); p = P_phys worker processes.
  Strategy 1: contiguous block static  [t*N/p, (t+1)*N/p)
  Strategy 2: cyclic round-robin static  i = t, t+p, t+2p, ...
  Strategy 3: shared-memory dynamic chunk queue, mp.Value('i', 0) counter,
              C in {1, 4, 16, 64, 256, 1024}
Each worker writes its active time t_worker[t] (ms) to a shared mp.Array('d', p).

Fairness: the same persistent workers execute every configuration, and the 8
configurations are run in INTERLEAVED rounds (round r runs all 8 once), so slow
thermal / turbo drift of the laptop affects all strategies equally instead of
penalising whichever strategy happens to run last.
"""
import argparse
import math
import multiprocessing as mp
import time

from harness import (STUDENT_ID, emit_verify_tag, header, ProcGroup, summarize,
                     save_json, common_args, resolve_pphys)

N_ITEMS = 12_000
CHUNKS = [1, 4, 16, 64, 256, 1024]
MODE_BLOCK, MODE_CYCLIC, MODE_DYNAMIC = 0, 1, 2


def K(i: int) -> int:
    return 1 + (i * i) // 3600            # exact integer form of 1 + floor((i/60)^2)


def work_item(i: int) -> float:
    sin, cos, sqrt = math.sin, math.cos, math.sqrt
    x = (i + 1) * 1e-3
    for _ in range(K(i)):
        x = sin(x) + cos(x)
        x = sqrt(x * x + 1.0)
    return x


def sched_worker(t, p, times, counter, mode, chunk):
    """One scheduling run for worker t; strategy selected by shared mode/chunk values."""
    m, C = mode.value, chunk.value
    acc = 0.0
    t0 = time.perf_counter()
    if m == MODE_BLOCK:
        for i in range(t * N_ITEMS // p, (t + 1) * N_ITEMS // p):
            acc += work_item(i)
    elif m == MODE_CYCLIC:
        for i in range(t, N_ITEMS, p):
            acc += work_item(i)
    else:
        lock = counter.get_lock()
        while True:
            with lock:                                 # synchronized shared index
                start = counter.value
                counter.value = start + C
            if start >= N_ITEMS:
                break
            for i in range(start, min(start + C, N_ITEMS)):
                acc += work_item(i)
    times[t] = (time.perf_counter() - t0) * 1e3        # ms


def main():
    ap = common_args(argparse.ArgumentParser(), warmup=1, runs=5)
    args = ap.parse_args()
    header("PHASE 4 -- Skewed Workloads, Load Imbalance & Dynamic Work Stealing")
    p = resolve_pphys(args)
    total = sum(K(i) for i in range(N_ITEMS))
    print(f"p = P_phys = {p}  N = {N_ITEMS:,}  K(0) = {K(0)}  K(N-1) = {K(N_ITEMS - 1):,}  "
          f"total iterations = {total:,}")
    print(f"warmup rounds = {args.warmup}, timed rounds = {args.runs} (all 8 configs interleaved per round)")
    blk = [sum(K(i) for i in range(t * N_ITEMS // p, (t + 1) * N_ITEMS // p)) for t in range(p)]
    cyc = [sum(K(i) for i in range(t, N_ITEMS, p)) for t in range(p)]
    print(f"Analytical lambda from K(i): block = {max(blk) / (sum(blk) / p):.3f}, "
          f"cyclic = {max(cyc) / (sum(cyc) / p):.4f}")

    configs = [("Strategy 1: block static", MODE_BLOCK, 0),
               ("Strategy 2: cyclic static", MODE_CYCLIC, 0)] + \
              [(f"Strategy 3: dynamic C={c}", MODE_DYNAMIC, c) for c in CHUNKS]

    times = mp.Array("d", p)
    counter = mp.Value("i", 0)
    mode = mp.Value("i", 0)
    chunk = mp.Value("i", 1)
    samples = {name: [] for name, _, _ in configs}

    with ProcGroup(sched_worker, [(t, p, times, counter, mode, chunk) for t in range(p)]) as g:
        def run_once(m, c):
            mode.value, chunk.value, counter.value = m, max(c, 1), 0
            for t in range(p):
                times[t] = 0.0
            t0 = time.perf_counter_ns()
            g.run()
            wall = (time.perf_counter_ns() - t0) / 1e6
            tw = list(times)
            return wall, max(tw) / (sum(tw) / p), tw

        for r in range(args.warmup + args.runs):
            tag_r = "warm-up" if r < args.warmup else f"timed {r - args.warmup + 1}/{args.runs}"
            for name, m, c in configs:
                res = run_once(m, c)
                if r >= args.warmup:
                    samples[name].append(res)
            print(f"  round {r + 1} ({tag_r}) done", flush=True)

    rows = []
    for name, m, c in configs:
        res = samples[name]
        st = summarize([x[0] for x in res])
        med = sorted(res, key=lambda x: x[0])[len(res) // 2]       # run with median T_wall
        rows.append({"name": name, "mode": m, "C": c or None, "median_ms": st.median_ms,
                     "iqr_ms": st.iqr_ms, "min_ms": st.min_ms, "max_ms": st.max_ms,
                     "lambda": med[1], "lambda_mean": sum(x[1] for x in res) / len(res),
                     "t_worker_ms": med[2], "sum_t_worker_ms": sum(med[2])})

    print(f"\n{'configuration':<27} {'T_wall ms':>10} {'IQR':>8} {'lambda':>7} {'sum t_w ms':>11}  t_worker[ms]")
    for r in rows:
        tw = " ".join(f"{x:.0f}" for x in r["t_worker_ms"])
        print(f"{r['name']:<27} {r['median_ms']:>10.1f} {r['iqr_ms']:>8.1f} {r['lambda']:>7.3f} "
              f"{r['sum_t_worker_ms']:>11.0f}  [{tw}]")

    dyn = [r for r in rows if r["mode"] == MODE_DYNAMIC]
    best = min(dyn, key=lambda r: r["median_ms"])
    T1 = rows[0]["median_ms"]
    print(f"\nC* = {best['C']}: T_wall = {best['median_ms']:.1f} ms, lambda = {best['lambda']:.3f}; "
          f"speedup over block static = {T1 / best['median_ms']:.3f}x")
    c1 = next(r for r in dyn if r["C"] == 1)
    cbig = next(r for r in dyn if r["C"] == 1024)
    last_start = (N_ITEMS - 1) // 1024 * 1024
    tail_share = sum(K(i) for i in range(last_start, N_ITEMS)) / total * 100
    first_full = sum(K(i) for i in range(last_start - 1024, last_start)) / total * 100
    print(f"C=1    : {N_ITEMS:,} lock acquisitions; lambda = {c1['lambda']:.3f}; T = {c1['median_ms']:.1f} ms")
    print(f"C=1024 : {math.ceil(N_ITEMS / 1024)} chunks; final chunk items {last_start}..{N_ITEMS - 1} "
          f"= {tail_share:.1f}% of all work (previous chunk {first_full:.1f}%); "
          f"lambda = {cbig['lambda']:.3f}; T = {cbig['median_ms']:.1f} ms")
    print(f"Mean work per item = {total / N_ITEMS:,.0f} iterations")

    tag = emit_verify_tag("PHASE4", STUDENT_ID, T1, best["median_ms"])
    print("\n" + tag)
    save_json("phase4.json", {"P_phys": p, "rows": rows, "C_star": best["C"], "verify": tag})


if __name__ == "__main__":
    main()
```

```python
"""
run_all.py -- runs Phase 0..4 one after another and saves each console output
to results/phaseN_output.txt (JSON results are saved by each task as well).

Usage:   python run_all.py            # all phases
         python run_all.py 1 3        # only phases 1 and 3 (3 = 3a + 3b)
Close other heavy programs and keep the laptop plugged in while it runs.
"""
import os
import subprocess
import sys
import time

HERE = os.path.dirname(os.path.abspath(__file__))
TASKS = {
    "0": "task0_cal.py",
    "1": "task1_falsesharing.py",
    "2": "task2_scaling.py",
    "3a": "task3a_roofline.py",
    "3b": "task3b_gemm.py",
    "4": "task4_scheduling.py",
}


def main():
    phases = [a.lower() for a in sys.argv[1:]] or list(TASKS)
    if "3" in phases:
        i = phases.index("3")
        phases[i:i + 1] = ["3a", "3b"]
    out_dir = os.path.join(HERE, "results")
    os.makedirs(out_dir, exist_ok=True)
    for ph in phases:
        script = os.path.join(HERE, TASKS[ph])
        log_path = os.path.join(out_dir, f"phase{ph}_output.txt")
        print(f"\n>>> Running {TASKS[ph]}  (log -> results/phase{ph}_output.txt)", flush=True)
        t0 = time.time()
        with open(log_path, "w", encoding="utf-8") as log:
            proc = subprocess.Popen([sys.executable, "-u", script], cwd=HERE,
                                    stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
                                    text=True, encoding="utf-8", errors="replace")
            for line in proc.stdout:
                sys.stdout.write(line)
                log.write(line)
            proc.wait()
        print(f"<<< {TASKS[ph]} finished in {time.time() - t0:.0f} s (exit code {proc.returncode})")
    print("\nVERIFY lines:")
    for ph in phases:
        p = os.path.join(out_dir, f"phase{ph}_output.txt")
        if os.path.exists(p):
            for line in open(p, encoding="utf-8"):
                if line.startswith("VERIFY_HASH"):
                    print(line.rstrip())


if __name__ == "__main__":
    main()
```
